Логотипы лаунчеров для мастера сборок. Принадлежат их владельцам и показываются только для обозначения совместимости.
modrinth, prism, atlauncher, gdlauncher: из открытых репозиториев проектов.
multimc, lunar: иконки из набора Papirus (GPL-3.0).
curseforge: глиф наковальни из Simple Icons (CC0) на тёмной плитке.
dawn: запасной значок (перо из Lucide, ISC), официального логотипа получить не удалось.
Чтобы поставить свой логотип, положи файл <id>.svg или <id>.png рядом (png для modrinth, atlauncher, gdlauncher; svg для остальных).
