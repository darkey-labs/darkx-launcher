# DarkX Launcher

Лаунчер Minecraft на **Electron 20** (последняя ветка с поддержкой Windows 7/8/8.1).
Аккаунты, автоустановка Fabric + Fabric API, Java от Mojang, ассеты, запуск, консоль, DarkX Visuals по ссылке.

## Запуск и сборка (Windows)
Нужен Node.js (LTS) — https://nodejs.org
- `start.bat` — запуск в режиме разработки (первый раз сам поставит зависимости)
- `build.bat` — тесты + установщик и portable-версия в папке `dist\`

Вручную: `npm install`, `npm start`, `npm test`, `npm run dist`.

## Что умеет
- **Аккаунты:** оффлайн (ник) и Microsoft — выбираются в шапке слева сверху, «Новый аккаунт» открывает окно выбора. Токены Microsoft шифруются средствами системы (DPAPI на Windows).
- **Моды:** вкладка с пазлом. Modrinth работает сразу, CurseForge — если в сборку зашит API-ключ (`curseforgeKey` в `launcher.local.json`, ключ бесплатный на console.curseforge.com; без него вкладки CurseForge нет). Профиль, источник, сторона и категории — в правой панели. Обязательные зависимости ставятся сами.
- **Скины:** библиотека (по нику Mojang или PNG-файлом). «Применить» публикует скин под ником аккаунта в сеть DarkX (Firebase, узел `darkx/skins/<ник>`). В правилах базы этот узел должен быть открыт на запись.
- **Лента обновлений** на главной — 5 последних релизов репозитория из `releasesRepo` (`launcher.config.json`). Версия берётся из названия релиза, пункты — из описания.
- **Сборки:** для каждой своя папка (`миры`, `mods`, настройки). Крупная подпись на обложке — название сборки, у стандартной — версия с буквой `b` (например, `1.21.11b`). Обложка — официальный баннер 1.21.11 (`assets\cover.jpg`): у стандартной сборки центр картинки, у остальных свой участок по id. Баннер можно заменить своим файлом с тем же именем; пиксельный пейзаж из `cover.js` остаётся запасным, если файла нет.
- **Мастер создания сборок** (кнопка-шеврон у «Запустить» или вкладка «Сборки»):
  - *Создать новую сборку* — «Создать сразу» одним кликом (последняя версия + Fabric + DX Visuals) или с выбором версии и загрузчика.
  - *Миграция с других лаунчеров* — Modrinth App, CurseForge (Overwolf), Prism Launcher, ATLauncher, Dawn (Feather), MultiMC, GDLauncher, Lunar Client. Лаунчер сам находит их папки, показывает сборки (версия, загрузчик, число модов и миров), копирует миры, ресурспаки, настройки и моды. Исходные файлы не трогаются. Папку можно указать вручную. Версия Minecraft берётся из данных лаунчера, а если их нет — из `fabric.mod.json` модов; если и так не нашлась — выбирается в списке.
  - Поддерживается загрузчик Fabric и чистый Minecraft. Из сборок на Forge, NeoForge и Quilt переносятся миры, ресурспаки и настройки, а моды — нет (они не заработают без своего загрузчика). Lunar Client переносит только данные из `.minecraft` (его собственные моды живут внутри клиента).
- **Сервер для быстрого входа:** рядом с «Запустить» — кнопка с сетью серверов. Добавь адрес (`mc.example.com` или `host:порт`), иконка подтянется с сервера, а нажатие на неё выбирает сервер: после запуска игра зайдёт на него сама (`--quickPlayMultiplayer`, для версий до 1.20 — `--server`/`--port`).
- **Экран запуска** — на весь экран, со случайным советом (меняется каждые 7 секунд), шагом установки и кнопкой «Прервать»: текущие файлы дозагружаются, новые не начинаются. Заголовок на главной тоже случайный и меняется при каждом запуске. Тексты — в `renderer/greet.js` (`TITLES`, `TIPS`), переводы — в `i18n.js`.
- **Автоустановка:** клиент и библиотеки с серверов Mojang (с проверкой sha1), ресурсы, Fabric Loader с meta.fabricmc.net,
  Fabric API с Modrinth, Java (тот же рантайм, что у официального лаунчера). Уже скачанное не качается повторно.
- **DarkX Visuals:** прямая ссылка на `.jar` задаётся только в `launcher.config.json` → `darkxClientUrl`, в Настройках её нет.
  При каждом запуске лаунчер проверяет, изменился ли файл на сервере (ETag / размер), и обновляет мод.
- **Консоль** игры в лаунчере, лог пишется в `game\logs\latest.log`.
- **Темы:** те же 8 акцентов, что в клиенте (по умолчанию оранжевый).

Данные лежат в `%APPDATA%\DarkXLauncher` (кнопка «Открыть папку данных» в Настройках).

## Вход через Microsoft: Azure Client ID
Вход использует device code flow и нужен собственный Client ID:
1. https://portal.azure.com → Microsoft Entra ID → App registrations → New registration.
2. Тип аккаунтов: **Personal Microsoft accounts only**. Redirect URI не нужен.
3. Authentication → **Allow public client flows = Yes**.
4. Скопируй Application (client) ID в `launcher.local.json` → `msClientId` (в Настройках этого поля нет, значение вшивается в сборку).
5. Mojang требует одобрения приложения для Minecraft API: форма https://aka.ms/mce-reviewappid.
   Пока одобрения нет, вход вернёт «Invalid app registration». Оффлайн-аккаунты работают без всего этого.

## Языки
Настройки → «Язык»: русский, English, українська, беларуская. Переключение сразу, без перезапуска. Весь текст интерфейса и сообщения об ошибках переводятся из одного словаря `renderer/i18n.js` (ключ — русская фраза, дальше столбцы en, uk, be). Новый текст в интерфейсе: пиши по-русски как обычно и добавь строку в `ROWS`; пока перевода нет, показывается русский. Описания релизов с GitHub и каталог модов приходят уже готовыми и не переводятся.

## Обновление лаунчера (OTA)
Лаунчер сам проверяет последний релиз в GitHub-репозитории `launcherRepo` (`launcher.config.json`, по умолчанию `darkey-labs/darkx-launcher`): через 4 секунды после запуска и по кнопке в Настройках → «Лаунчер». Если версия новее, в боковой панели появляется кнопка со стрелкой; окно показывает, что нового, и ставит обновление в один клик.

Как выпустить обновление:
1. Подними `version` в `package.json` (например, `1.0.1`) и собери `build.bat`.
2. В GitHub создай релиз с тегом `v1.0.1` и приложи файлы из `dist\`: `DarkX-Launcher-Setup-1.0.1-x64.exe` (и `-ia32`) и `DarkX-Launcher-Portable-1.0.1.exe`. `latest.yml` и `blockmap` не нужны.
3. Текст релиза показывается в окне обновления (список через `-`).

Установленная версия ставит новый установщик тихо поверх старой и запускается заново, portable-версия подменяет свой exe. Файл скачивается только с github.com, проверяются размер и sha256 (GitHub отдаёт его в `digest`). Установщик не подписан, поэтому Windows SmartScreen может показать предупреждение. В режиме `npm start` обновление не ставится, только показывается. Если включено «Ставить обновления сами» (по умолчанию да), лаунчер при запуске сам скачает и поставит новую версию и перезапустится; одну и ту же версию он сам пробует только один раз, чтобы не уйти в петлю перезапусков (кнопка «Обновить» работает всегда). Обе опции выключаются в Настройках → «Лаунчер».

## Шрифты
Интерфейс — Montserrat (OFL), ник на главной — **Minecraft Five**. Сам шрифт в архив не входит: положи `MinecraftFive-Regular.woff2` (или `.woff`, `.otf`, `.ttf`) в `assets\fonts\` — подхватится сам. Пока файла нет, ник рисуется похожим пиксельным шрифтом Silkscreen (OFL). Права на сам Minecraft Five принадлежат Mojang — проверь условия, если будешь распространять лаунчер вместе с файлом шрифта.

## Структура
- `main/main.js` — окно и IPC; `main/preload.js` — безопасный мост (contextIsolation, sandbox)
- `main/lib/` — `http` (без зависимостей, Node 16), `versions` (манифесты, правила, аргументы), `installer`, `java`, `mods`, `accounts`, `launch`, `store`, `importers` (перенос из других лаунчеров), `ping` (Server List Ping: иконки серверов)
- `renderer/` — интерфейс на Tailwind (OLED, без чистого белого); `npm run css` пересобирает `style.css`. `wizard.js` — мастер сборок, `cover.js` — обложки, `greet.js` — заголовки и советы
- `test/` — тесты ядра на подменённой сети (`run.js`, `mocknet.js`), тесты переноса на синтетических папках лаунчеров (`importers.js`, `fixtures.js`) и скриншот-прогон `shot.js` в настоящем Electron

## Ограничения
- Форматы данных Dawn (Feather), Lunar Client, GDLauncher и ATLauncher разобраны по открытой документации и общим признакам и на реальных установках не проверялись; Prism, MultiMC, CurseForge и Modrinth App читаются по описанным форматам (для Modrinth — база `app.db`). Если лаунчер найден, но версия не определилась, её можно выбрать вручную.
- Minecraft 1.21.x требует Java 21, а она официально не поддерживает Windows 7/8. Лаунчер запустится, игра может нет.
- Установщик пока без подписи кода: SmartScreen покажет предупреждение.

## Какой jar мода ставится

При каждом запуске лаунчер смотрит релизы репозитория из `releasesRepo`, оставляет те, чей тег начинается с нужной версии игры (`1.21.11`, `1.21.11-U9`, `1.21.11-U9-P1`), и берёт .jar из самого свежего по дате публикации. Имя файла может быть любым, одинаковым во всех релизах тоже можно. Ссылка `darkxClientUrl` из `launcher.config.json` нужна только как запасная, если GitHub недоступен. В журнале запуска видно, откуда поставлено: `DarkX Visuals: updated (релиз 1.21.11-U9-P1)`.

## Параметры сборки

Ссылка на клиент, адрес базы, ключ CurseForge и Azure Client ID в интерфейсе не меняются. Публичные значения лежат в `launcher.config.json`, ключи — в `launcher.local.json` (в git не попадает, шаблон — `launcher.local.example.json`). Файл читается при запуске и переопределяет `launcher.config.json`. Перед `npm run dist` заполни его.
